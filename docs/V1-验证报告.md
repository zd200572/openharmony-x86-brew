## x86_64 适配补丁(共 4 类,均已归档)

上游从未在 rk3568 产品 + x86_64 组合下跑过构建(模拟器产品不走 rk3568 板级),暴露 4 类问题:

1. **GN import 作用域 defines 碰撞**:`camera.gni` 在 `is_emulator`(x86_64 时为真)分支导出 `defines=[V4L2_EMULATOR]`,与 `device.gni` 的 defines 导出在任何同时引用两者的作用域冲突。修:camera.gni 改追加式;device.gni 移除顶层 defines 导出(相机板级代码不参与本构建)。
2. **x86_64 专属依赖在发布包中缺仓**:arkcompiler 静态编译器仅 x86_64 分支引用 `third_party/asmjit`、`third_party/zydis`,7.0 发布 tar 不含这两仓(gitee/gh-proxy 当时均不可达)。修:写空 stub BUILD.gn(仅提供 load 期标签)+ 注释 code_generator/BUILD.gn 两处 include_dirs(这些目标不在容器构建闭包)。
3. **板级 blob 无 x86_64 文件**:rk3568 GPU(mali)/rga 等预编译库无 x86_64 二进制 → prebuilt 模板断言失败。修:`build/templates/cxx/prebuilt.gni` 对 x86_64 合成空占位文件(通用解,一次覆盖整类);GPU BUILD.gn 补 x86_64 分支。
4. **杂项**:GN `exec_script` 需要 `/usr/bin/python`(补 python3 软链);openssl 3.0 linux-x86_64 安装到 lib64 而 curl 只认 lib(建软链);hilog 补丁防重复应用(改 dry-run -R 检测)。
